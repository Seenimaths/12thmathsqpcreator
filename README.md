# Class XII Mathematics Question Paper Studio — Final Edition (v5.0)

A self-contained, mobile-friendly web application for creating Tamil Nadu State Board Class XII Mathematics examination papers (`90 Marks Public Exam`, `50 Marks`, `25 Marks`, and `Custom` patterns) with instant **Tamil (`தமிழ்`)**, **English**, and **Bilingual** switching.

## Key Features in Final Edition (v5.0)
- **Editable School Name Box in Question Paper Heading**: Includes a bordered School / Institution Name box at the top of the Question Paper and Answer Key headings, editable both in the sidebar and directly on the paper.
- **Single-Row Quad-Space MCQ Options & Exact 2-Page Default Layout**: All 4 MCQ options `(a) ... (b) ... (c) ... (d)` are formatted in a single horizontal row with quad spacing (`4 columns per row`), calibrated so a 90-Mark paper fits into an **Exact 2-Page Layout** by default, with dynamic scaling to **3 Pages** or **4 Pages** when adjusting the Font Size slider.
- **Complete 2,092 Bilingual + PDF Creative Question Bank**: Includes all Volume I & II Textbook Exercises, Examples, Book-Back MCQs, **Come-Book Creative One-Mark MCQs (Pages 68–79)**, and all **46 Previous Year Public Creative Questions (Pages 80–81)** in both Tamil and English.
- **Full Concrete Step-by-Step Answer Keys with Dual KaTeX + MathJax Rendering**: Every question includes a complete step-by-step mathematical marking scheme (`[1M]`, `[2M]`, etc.) rendered cleanly via KaTeX and MathJax.
